# Vite Admin Dashboard Template

基于 Vite + React + TypeScript 的管理后台模板

## 特性

- ⚡️ Vite - 极速开发体验
- ⚛️ React 19 - 最新 React 特性
- 🔷 TypeScript - 类型安全
- 🎨 Tailwind CSS - 实用优先的 CSS 框架
- 🔒 RBAC - 完整的权限控制系统
- 📊 D3.js Charts - 数据可视化
- 🌍 i18n - 国际化支持
- 📱 响应式设计

## 快速开始

### 安装依赖

# 使用 pnpm
pnpm install

# 使用 npm
npm install

yarn### 开发模式
